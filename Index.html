📄 วิธีแปลงเป็น PDF

ไฟล์ .docx ถูก download แล้ว — เปิดด้วย Word/LibreOffice แล้ว Save as PDF เพื่อให้ได้ PDF ที่ตรงกับ Master 100%

1
เปิดไฟล์ .docx ที่เพิ่ง download ด้วย Microsoft Word (หรือ LibreOffice Writer)
2
Microsoft Word: ไปที่ File → Save As → เลือกชนิดไฟล์เป็น PDF (*.pdf) → Save
LibreOffice: File → Export As → Export as PDF
3
ได้ PDF ที่ ฟ้อน TH Sarabun New + ลายน้ำ Humansoft + header/footer ครบ 100% ตรงกับ Master
💡 ทางลัดบน Mac: File → Print → คลิก PDF มุมล่างซ้าย → Save as PDF
💡 บน Windows: Ctrl+P → Printer = Microsoft Print to PDF → Print
